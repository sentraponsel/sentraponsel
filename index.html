Belum masuk
Memerlukan proyek Firebase milik Tuan, Authentication Email/Password, Cloud Firestore, serta aturan keamanan. Konfigurasi proyek bukan password, tetapi akun dan aturan database harus diamankan. Sinkronisasi cloud hanya aktif setelah login.

☁ Google Drive

Tautkan email Google pribadi untuk menyimpan cadangan langsung ke Drive.
Belum terhubung
Buat OAuth Client ID tipe Web di Google Cloud Console, aktifkan Google Drive API, dan masukkan origin hosting aplikasi pada Authorized JavaScript origins.
Data disimpan sebagai satu file cadangan Sentra Ponsel di Google Drive Anda.
Sinkron otomatis belum diaktifkan
Perlu Google OAuth Client ID, Google Drive API aktif, serta hosting HTTPS dengan origin yang diizinkan. Persetujuan Google pertama kali harus dilakukan manual. Browser tidak menyimpan refresh token; jika Google meminta izin ulang atau token kedaluwarsa, hubungkan kembali. Status sinkron menunjukkan apakah unggahan terakhir berhasil.

✆ WhatsApp Owner

Kirim laporan secara manual atau kirim otomatis melalui API WhatsApp Business pihak Anda.
API WhatsApp membutuhkan provider/API resmi dan endpoint yang sesuai. Untuk produksi, gunakan backend proxy agar token tidak tersimpan terbuka di browser.

⛨ Keamanan aplikasi

PIN dan biometrik belum dikonfigurasi.
